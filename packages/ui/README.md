# `@eutheto/ui` (reserved)

Future shared presentation primitives for eutheto frontends. This directory intentionally has no `package.json`, so it is not an installed pnpm workspace project, publishable package, or implemented API.

## Boundary

It may contain accessible, themeable UI building blocks, but never scenario authority, Tauri calls, persistence, credentials, or solver logic.

The owning roadmap phase must decide whether this responsibility still needs a separate package, then add a private/public decision, dependencies, implementation, and tests. The exact package inventory remains an explicit gate; this reserved npm-style name does not freeze it.
