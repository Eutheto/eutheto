# `eutheto-domain-ir` (reserved)

This directory reserves the roadmap boundary for **future normalized domain representation shared by domain packs and verification.** No `Cargo.toml` is present, so this is not a Cargo workspace member, implemented crate, or published API.

## Boundary

It must remain independent of official pack implementations, UI frameworks, databases, and backend-native models.

The owning roadmap phase must confirm that this boundary still warrants a separate crate, choose its dependencies, and add implementation and tests. The exact future crate inventory is an explicit architecture gate; the reserved name alone does not settle it.
