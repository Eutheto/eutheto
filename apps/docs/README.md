# Documentation application (reserved)

This directory reserves the post-MVP Nuxt documentation application described by the roadmap. It is not part of the Phase-00 product surface and intentionally has no `package.json`, Nuxt configuration, generated site, deployment target, or pnpm workspace project.

The future application may present project and domain documentation, but it must consume approved contracts and implemented behavior rather than becoming an authority for scenarios, commands, compatibility, or releases. Its framework version, hosting organization, deployment identity, package boundaries, accessibility evidence, and release process remain decisions for the owning post-MVP phase.

Until those gates close, project documentation remains in `docs/`; this reservation must not be represented as a working or published website.
